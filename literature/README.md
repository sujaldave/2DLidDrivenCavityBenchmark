# Literature data

These CSV files transcribe the benchmark values reported by:

> U. Ghia, K. N. Ghia, and C. T. Shin, “High-Re solutions for
> incompressible flow using the Navier–Stokes equations and a multigrid
> method,” *Journal of Computational Physics* 48 (1982), 387–411.
> <https://doi.org/10.1016/0021-9991(82)90058-4>

- `ghia_table_I_u.csv`: horizontal velocity `u` along the vertical
  centerline `x = 0.5` (Table I).
- `ghia_table_II_v.csv`: vertical velocity `v` along the horizontal
  centerline `y = 0.5` (Table II).
- `ghia_vortex_centers.csv`: vortex-center coordinates and extremum type
  (Table V).
